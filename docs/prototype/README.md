# 连接状态指示器 · UI 原型

一次性原型，不属于插件代码，只用来回答一个设计问题：**在 36px 高、右侧只有 ~60px 余量的顶栏里，怎样让用户一眼看出 Zotero 本地 API 的连接状态（绿/黄/红），又不挤压条目内容、不打断阅读？**

## 打开

双击 `status-indicator.html`（file:// 即可，零依赖、无网络请求）。页面底部深色胶囊是原型工具条，不属于设计本身。

- 方案：`?variant=E|A|B|C|D`（默认 E；← / → 键或底部箭头循环）
- 状态：`?state=green|amber|red`
- 宽度：`?w=320|480|1000`（右侧栏窄态 / 常规 / 展开全屏）
- 主题：`?theme=light|dark`

## 选定方案：E 胶囊 + 引导条

顶栏用 A 的胶囊（圆点 + 短文案，位于「806 条」之后、排序之前，排序始终最右）；**非绿色**时顶栏下滑出整宽引导条（无圆点、状态色底、底部 1px 分隔线），一句话写原因 + 右侧「打开 Zotero」「重新检测」；**绿色**时提示条高度严格为 0，面板恢复干净单行。

320px 窄栏：胶囊按 A 的规则收成圆点（原生 title 兜底），引导条自动变两行（文字一行、按钮一行）。

## 其余方案（保留作对照）

| 方案 | 形态 | 取舍 |
| --- | --- | --- |
| A 状态胶囊 | 只有顶栏里的胶囊 | 最直接，但出问题时没有下一步 |
| B 信号图标 | 三根信号条 + 灰色文案，悬停出浮层 | 最克制，信息要悬停才看得到 |
| C 边缘色条 | 面板上沿 2px 状态色，状态并进计数行 | 最安静，红色态辨识度偏弱 |
| D 引导展开条 | 只有引导条，顶栏只留圆点 + 短文案 | 提示充分，但平时信息量偏少 |

## 状态与文案

- 绿 `#1a7f37` 已连接 —— Zotero 本地 API 正常响应
- 黄 `#b58a00` 未就绪 —— Zotero 未运行，或本地 API 未开启
- 红 `#b3261e` 连接失败 —— 无法访问本机 Zotero

颜色沿用插件 `src/client/styles.ts` 里的 `--dsw-alias-state-*` 取值，落地时无需新造色。
